Programação Orientada a Objetos (POO) – UniRios 2026.2

Repositório com os códigos desenvolvidos nas aulas da disciplina de Programação Orientada a Objetos, em Java, do curso de Sistemas de Informação do Centro Universitário UniRios.

Os exemplos acompanham as aulas e servem como material de apoio para estudo, revisão e prática.

📂 Estrutura do repositório
Pasta	Conteúdo
Codigos_Aulas_2026/	Códigos das aulas do semestre atual (1ª e 2ª etapas)
Codigos_Aulas_2025/	Códigos de turmas anteriores, para consulta
Projeto_Login_mvc_dao/	Projeto de exemplo de tela de login usando os padrões MVC e DAO com acesso a banco de dados

📚 Conteúdos abordados
Classes, objetos, atributos e métodos
Encapsulamento, construtores, getters e setters
Herança e polimorfismo
Classes abstratas e interfaces
Coleções e tratamento de exceções
Padrão MVC (Model–View–Controller)
Padrão DAO e conexão com banco de dados

▶️ Como usar
Opção 1: clonar pelo IntelliJ
Abra o IntelliJ IDEA e vá em File → New → Project from Version Control.
Cole a URL do repositório:
https://github.com/RomarioGit/poo-unirios-aulas
Clique em Clone.
Opção 2: baixar o ZIP

Clique no botão verde Code → Download ZIP, extraia e abra a pasta no IntelliJ.

Requisito: ter o JDK (Java) instalado e configurado no IntelliJ.

🔄 Mantendo atualizado

O repositório é atualizado ao longo do semestre. Se você clonou, use Git → Pull no IntelliJ (ou git pull no terminal) para baixar os códigos das aulas mais recentes.
